<br/>

> **Vibeesta** is a student-focused social platform engineered around **campus culture, student communities, creators, and real-time interaction**.

### 🌟 Key Highlights & Modules

* 🏛️ **College-Based Communities:** Dedicated spaces tailored to campus networks and universities.
* 📰 **Personalized Feeds:** Context-aware content delivery connecting students with peer updates.
* 🎬 **Short-Form Content & Stories:** Multimedia creator experiences built for student engagement.
* 📅 **Campus Events & Meetups:** Real-time event discovery and ticketing integration.
* 💬 **Real-Time Messaging:** High-speed peer-to-peer and group chat infrastructure.
* 🎨 **Creator-Focused Ecosystem:** Tools for student creators and campus clubs to build audiences.

### 🛠️ Production Architecture

```text
  ┌─────────────────────────────────────────────────────────┐
  │                 📱 Flutter Mobile App                   │
  │        (Cross-Platform iOS/Android UI & State)          │
  └───────────────────────────┬─────────────────────────────┘
                              │ HTTPS / WSS
                              ▼
  ┌─────────────────────────────────────────────────────────┐
  │              ⚙️ Node.js + Express API Cluster           │
  │          (Auth, Business Logic, Real-Time Engine)       │
  └───────────────────────────┬─────────────────────────────┘
                              │
                              ▼
  ┌─────────────────────────────────────────────────────────┐
  │                 🗄️ PostgreSQL Database                  │
  │           (Structured Relational Data Store)            │
  └───────────────────────────┬─────────────────────────────┘
                              │
                              ▼
  ┌─────────────────────────────────────────────────────────┐
  │          🐳 Dockerized Container Environment            │
  │     (Isolated Services, CI/CD Automated Pipelines)     │
  └───────────────────────────┬─────────────────────────────┘
                              │
                              ▼
  ┌─────────────────────────────────────────────────────────┐
  │          ☁️ DigitalOcean Droplets & Infrastructure      │
  │             (Production Cloud Hosting & CDN)            │
  └─────────────────────────────────────────────────────────┘
```

**Tech Stack:** `Flutter` `Dart` `Node.js` `Express` `PostgreSQL` `Docker` `DigitalOcean` `Git`
